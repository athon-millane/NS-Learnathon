## Introduction

In this lesson, we focus on building a flexible training framework called "the learner". The goal is to create a system that allows for easy monitoring, customization, and debugging of model training through callbacks.

## The Basic Callbacks Learner

We start with an intermediate step towards our flexible framework:

- The Basic Callbacks Learner has similar structure to a simple Learner:
  - `fit()` method to loop through epochs
  - `one_epoch()` to process each batch in a DataLoader
  - `one_batch()` to process individual batches of data

The key enhancement is the addition of a callback system with `before_*` and `after_*` methods that get called at specific points in the training process:

```python
# Example callback structure
def callback(self, name):
    return self._run_cbs(self.cbs, name)

def _run_cbs(self, cbs, method_name):
    # Sort callbacks by order
    # Run the specified method on each callback
```

### Understanding Callbacks

A callback is a class where you can define methods like:
- `before_fit()` / `after_fit()`
- `before_epoch()` / `after_epoch()`
- `before_batch()` / `after_batch()`

Example of a simple callback:

```python
class CompletionCB():
    def before_fit(self): self.count = 0
    def after_batch(self): self.count += 1
    def after_fit(self): print(f"Completed {self.count} batches")
```

### Control Flow with Exceptions

The framework uses exceptions for control flow:
- `CancelFitException` - Stop the entire training run
- `CancelEpochException` - Skip to the next epoch
- `CancelBatchException` - Skip to the next batch

Example of a callback using exceptions:

```python
class SingleBatchCB():
    order = 1  # Higher order means it runs after callbacks with default order (0)
    def after_batch(self):
        raise CancelEpochException()
```

## Metrics

To track model performance, we need a way to calculate and display metrics:

### Creating a Metric Class

The Metric class provides functionality to:
- Store and calculate running statistics across batches
- Reset statistics at the start of epochs
- Calculate weighted averages for values like loss
- Compute metrics like accuracy

```python
class Metric:
    def reset(self):
        self.vals, self.ns = [], []
        
    def add(self, val, n=1):
        self.vals.append(val)
        self.ns.append(n)
        
    @property
    def value(self):
        return sum([v*n for v,n in zip(self.vals, self.ns)]) / sum(self.ns)
```

## The Flexible Learner

The flexible learner uses a context manager to streamline callback handling:

```python
@contextmanager
def callback_context(self, name):
    try:
        self.callback(f'before_{name}')
        yield
        self.callback(f'after_{name}')
    except globals()[f'Cancel{name.capitalize()}Exception']:
        pass
```

This allows for cleaner code:

```python
def fit(self, epochs, lr):
    self.epochs = epochs
    self.opt = self.opt_func(self.model.parameters(), lr)
    
    with self.callback_context('fit'):
        for self.epoch in range(epochs):
            self.one_epoch(True)
            self.one_epoch(False)
```

### Training Customization

The flexible learner allows customizing training behavior through callbacks or subclassing:

```python
class TrainCB():
    def predict(self):
        self.learn.preds = self.learn.model(self.learn.batch[0])
    
    def get_loss(self):
```

## Momentum Implementation

An interesting implementation of momentum by modifying the zero_grad method:

```python
class MomentumLearner(Learner):
    def __init__(self, model, dls, loss_func, lr=0.1, cbs=None, opt_func=SGD, momentum=0.85):
        self.momentum = momentum
        super().__init__(model, dls, loss_func, lr, cbs, opt_func)
    
    def zero_grad(self):
        # Instead of zeroing gradients, multiply them by momentum
        for p in self.model.parameters():
            if p.grad is not None:
                p.grad.data.mul_(self.momentum)
```

## Learning Rate Finder

A callback to find optimal learning rates:

```python
class LRFinderCB():
    def __init__(self, lr_mult=1.3):
        self.lr_mult = lr_mult
    
    def before_fit(self):
        self.lrs, self.losses = [], []
        self.min_loss = float('inf')
    
    def after_batch(self):
        if not self.learn.training: raise CancelEpochException()
        # Record learning rate and loss
        self.lrs.append(self.learn.opt.param_groups[0]['lr'])
        loss = to_cpu(self.learn.loss)
        self.losses.append(loss)
        # Check if loss is getting worse
        if loss < self.min_loss: self.min_loss = loss
        if loss > self.min_loss*3: raise CancelFitException()
        # Increase learning rate
        for pg in self.learn.opt.param_groups:
            pg['lr'] *= self.lr_mult
```

## Visualizing Model Internals with Hooks

To understand what's happening inside a model during training:

### Creating Custom Hooks

```python
class Hook():
    def __init__(self, m, f):
        self.hook = m.register_forward_hook(partial(f, self))
    
    def remove(self): self.hook.remove()
    def __del__(self): self.remove()

def append_stats(hook, mod, inp, outp):
    if not hasattr(hook, 'stats'): hook.stats = []
    outp = to_cpu(outp)
    hook.stats.append((outp.mean(), outp.std()))
```

### Creating a Hooks Class

A convenient class to manage multiple hooks:

```python
class Hooks(list):
    def __init__(self, ms, f): super().__init__([Hook(m, f) for m in ms])
    def __enter__(self): return self
    def __exit__(self, *args): self.remove()
    def __del__(self): self.remove()
    def __delitem__(self, i): self[i].remove(); super().__delitem__(i)
    def remove(self): for h in self: h.remove()
```

## Analyzing Model Training

### Monitoring Activation Statistics

Key insights from activation statistics:
- Means should be close to zero
- Standard deviations should be close to one
- Avoid "dead units" where activations are very close to zero

### Colorful Dimension Histograms

Creating histograms of activation magnitudes:

```python
def append_stats(hook, mod, inp, outp):
    if not hasattr(hook, 'stats'): hook.stats = []
    outp = to_cpu(outp)
    hist = torch.histc(outp.abs(), bins=50, min=0, max=10)
    hook.stats.append((outp.mean(), outp.std(), hist))
```

These visualizations help identify:
- Dead neurons (very small activations)
- Exploding activations
- Distribution of activation values
