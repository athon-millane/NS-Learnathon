## Review of Stable Diffusion Concepts

### Basic Diffusion Process
1. Start with an image (e.g., a handwritten digit 7)
2. Add noise to create a noisy image
3. Train a U-Net to predict which pixels are noise
4. The U-Net compares its prediction to the actual noise and uses this loss to update weights
5. To make it easier, we can pass embeddings of the actual digit to the U-Net

### Text to Image Generation (CLIP)
- To handle text prompts like "a graceful swan" or "a scene from Hitchcock"
- Convert sentences into embeddings using CLIP
- CLIP was trained by downloading images with their ALT tags from the internet
- Two models are trained:
  - An image encoder that turns images into feature vectors
  - A text encoder that turns text into feature vectors
- Using Contrastive Loss (CL in CLIP), the model ensures text embeddings are close to their corresponding image embeddings

### Inference Process
1. Input a text prompt (e.g., "a smiling picture of Jeremy Howard")
2. Create random noise
3. Feed both into the U-Net
4. U-Net predicts which noise to remove
5. Subtract a bit of that noise from the image
6. Repeat the process multiple times (originally 1000 steps, now down to 60 or fewer)

## Recent Research Papers

### "Progressive Distillation for Fast Sampling of Diffusion Models"
- Uses a "distillation" process to reduce required steps from 60 to 4
- Teacher-Student approach:
  - Teacher Network: Original Stable Diffusion model (slow but accurate)
  - Student Network: Learns to skip steps
- Process:
  1. Train student to go directly from noise to timestep 2
  2. Use that student as the new teacher
  3. Train a new student to go directly from noise to two iterations of the previous student
  4. Repeat the process, doubling the number of steps each time (1→2, 2→4, 4→8, etc.)

### "On Distillation of Guided Diffusion Models"
- Extends the previous paper to work with Classifier Free Guided Diffusion
- Teaches the student model to handle guidance scales directly
- Guidance scale becomes an additional input to the student model
- Student learns to use Classifier Free Guided Diffusion in fewer steps

### "Imagic"
- Takes an input image and modifies it to match a text prompt while keeping everything else as similar as possible
- Examples:
  - A dog transformed into a sitting dog
  - A waterfall turned into a children's drawing of a waterfall
  - A person giving thumbs up, with crossed arms, or in namaste pose
- Process:
  1. Start with a pre-trained diffusion model
  2. Fine-tune the text embedding to make the diffusion model output something similar to the input image
  3. Lock that optimized embedding
  4. Fine-tune the entire diffusion model to output the original image
  5. Take the weighted average of the original target embedding and the fine-tuned embedding
  6. Pass that through the fine-tuned diffusion model

## Building a Stable Diffusion Pipeline from Scratch

### Pipeline Components
1. **CLIP Text Model**: Takes prompts and creates embeddings
2. **Tokenizer**: Splits text into words or sub-word units
3. **Autoencoder (VAE)**: Creates latent representations
4. **U-Net**: Core diffusion model
5. **Scheduler**: Controls noise schedule during diffusion process

### Pipeline Steps
1. Take a prompt (e.g., "an astronaut riding a horse")
2. Tokenize the prompt
3. Run tokens through CLIP encoder to get embeddings
4. Also get embeddings for an empty string (for classifier-free guidance)
5. Concatenate the two sets of embeddings
6. Create random noise (latents)
7. Scale the latents appropriately
8. Loop through diffusion steps:
   - Pass latents, time step, and prompt through U-Net
   - Get predictions for both conditional and unconditional results
   - Apply guidance scale
   - Update latents by removing some noise
9. Decode final latents using VAE
10. Scale output to 0-255 range for display

- Combine steps into functions to simplify the code
- Keep important code visible on one screen
- Use short variable names for mathematical operations
- Implement callbacks for flexibility
