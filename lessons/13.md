## 2. Neural Network Basics

### Understanding Linear Models

- Starting with a simple linear model where a single pixel value (X) is used to predict the probability (Y) of it being a specific digit (e.g., the number 3)
- Linear models are limiting because they can only represent straight lines, not complex curves
- To create more complex models, we can use rectified lines (lines that truncate at zero)
- By summing multiple rectified lines, we can approximate arbitrary curves

### Moving to Multiple Inputs

- Real-world problems have multiple inputs (e.g., all pixels in an image)
- For multiple pixels (inputs), we create planes rather than lines
- We can similarly add "rectified planes" together to create complex surfaces

## 3. Multi-Layer Perceptron Architecture

### Key Variables

- `n`: number of training examples (50,000 samples)
- `m`: number of pixels (784 pixels)
- `c`: number of possible outputs (10 possible digits)
- `nh`: number of hidden nodes/activations (arbitrarily set to 50)

### Matrix Operations

- Input shape: 50,000 rows (samples) × 784 columns (pixels)
- First weight matrix: 784 rows × 50 columns (for 50 hidden nodes)
- Result after first matrix multiply: 50,000 × 50
- After ReLU activation: still 50,000 × 50, but with values < 0 set to 0
- Second weight matrix: 50 rows × 1 column (simplified for MSE)
- Final output: 50,000 × 1 (one predicted digit per image)

### Loss Function

- Initially using Mean Squared Error (MSE) as a simplified loss function
- MSE is not ideal for classification but serves as a starting point
- Later improved to cross-entropy loss

## 4. Gradients and Derivatives

### Understanding Derivatives

- Derivatives are slopes that represent how one variable changes with respect to another
- For neural networks, we want to know how the loss changes as we adjust weights
- When we have multiple inputs and outputs, derivatives form a matrix (Jacobian matrix)
- The derivative of the loss with respect to weights tells us how to adjust weights to reduce loss

### The Chain Rule

- Chain rule: if y is a function of u, and u is a function of x, then dy/dx = (dy/du)(du/dx)
- Demonstrated with an interactive animation of connected wheels
- Essential for backpropagation because our neural network has multiple layers

### Application to Neural Networks

- Our neural network has multiple steps: linear → ReLU → linear → MSE
- Need to use chain rule to calculate derivatives through all these steps
- Backpropagation is essentially applying the chain rule layer by layer, backward

## 5. Implementing Backpropagation

### Forward and Backward Pass

- Forward pass: calculate loss by passing inputs through layers
- Backward pass: calculate gradients starting from the end and working backward
- Store gradients of each layer with respect to its inputs

### Using Python Debugger

- pdb.set_trace() used to debug and understand the code
- Commands like 'p' for print, 'w' for where, 'n' for next, 'c' for continue
- Useful for exploring calculations interactively

### Refactoring with Classes

- Created classes for each type of function (ReLU, Linear, MSE)
- Used Python's __call__ method to make classes behave like functions
- Each class handles both forward and backward passes for its specific operation
- Further improved by creating a Module class that other classes inherit from

## 6. PyTorch Implementation

## 7. Improved Loss Function: Cross Entropy

### Softmax and Log Softmax

- Replaced MSE with cross-entropy loss for classification
- Softmax: converts raw outputs to probabilities (sums to 1)
- Formula: e^(x_i) / ∑(e^(x_j))
- Log softmax: log of softmax, calculated with a numerical trick

### Log Sum Exp Trick

- Problem: e^x can create very large numbers leading to floating point errors
- Solution: subtract the maximum value before applying exp
- Formula: log(∑e^x_i) = a + log(∑e^(x_i-a)) where a = max(x_i)
- Makes calculations more numerically stable

### Cross Entropy Loss

- For one-hot encoded targets, cross-entropy simplifies to negative log of the target class probability
- Implemented using array indexing tricks in PyTorch
- PyTorch combines log_softmax and negative log likelihood in F.cross_entropy()

## 8. Training Loop

- Created a mini-batch training loop
- Forward pass: calculate predictions and loss
- Backward pass: calculate gradients
- Update weights: w = w - lr * w.g (weight minus learning rate times gradient)
- Zero gradients after each update
- Achieved ~97% accuracy on the training set after just 3 epochs
