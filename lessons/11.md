#### 2. Improved Update Process (Sebastian)
- Identified issue with diffusion updates: they can become too large
- Problem: `u + g * (t - u)` can make jumps too far when there's a big difference between `t` and `u`
- Solution: Scale the update by the ratio of the norms to keep updates at reasonable size
- Results: More texture in backgrounds, better detail in images 
- Several variations explored:
  - 1a → 1b: Rescaling the whole prediction (original approach in Lesson 9)
  - 2: Rescaling the update (changes direction of update)
  - 3: Both rescaling the difference and the result
- Note: Approach might already exist in a diffusion model for text-to-speech (Ben Poole from Google Brain)

#### 3. Decreasing Guidance Scale (Rekil Prashanth)
- Instead of keeping guidance scale at 7.5 throughout the process, decrease it
- Once the model knows what image to draw, let it "do its thing"
- Example with dog image: More texture, better details in eyes and fur
- Similar to approach suggested by instructor for modifying gradients with additional loss functions

## Part 2: Reading Research Papers - DiffEdit Paper

### How to Approach Research Papers
- Don't expect to understand every word
- Goal: Understand basic idea well enough to connect to code
- Use tools like Zotero to organize papers and add annotations
- Start with abstract and figures to understand what the paper is doing

### DiffEdit Paper Overview
- Title: DiffEdit for Semantic Image Editing
- Key idea: Edit an image based on a text query
- Unlike previous approaches, automatically generates the mask
- Example: Change "bowl of fruits" to "bowl of pears" or "basket of fruits"

### Navigating Different Paper Sections
- **Abstract**: Quick overview of what the paper does
- **Introduction**: More detailed explanation (often repeats abstract)
- **Related Work**: Context of how it fits with other approaches (can skip for first reading)
- **Background**: Mathematical foundation (often scary but just a reminder for those who know)
- **Method**: Most important part explaining the actual approach
- **Theoretical Analysis**: Often added for academic credibility (can skip)
- **Experiments**: Showcasing results
- **Appendices**: Often contain interesting examples and details

### Understanding Math Notation
- Learn the Greek alphabet to understand symbols
- Use tools like MathPix or Detexify to identify symbols
- Look up notation you don't understand (like vector norms)
- Extract LaTeX from papers to interpret equations
- Expected value (E) is an important concept in diffusion papers

### DiffEdit Method (3 Steps)
1. **Generate a mask**:
   - Add noise to input image
   - Denoise it twice:
     - Once using reference text (e.g., "horse")
     - Once using query text (e.g., "zebra")
   - Derive mask from difference between denoising results
   - Binarize the mask (turn into ones and zeros)

2. **Add noise to the original image**

3. **Decode using text query**:
   - Use mask to replace background with original pixel values
   - During diffusion, replace unmasked pixels with original

### Performance Improvement Methods

#### 1. Using Numba
- Add `@njit` decorator to compile Python to machine code
- First run compiles (slower), subsequent runs are much faster
- Improved implementation by making innermost loop a dot product
- Speed improvement from 448ms to 268μs (2000x faster)

#### 2. Using APL-style Operations
- Introduces element-wise operations
- Comparison with APL (Array Programming Language) syntax
- Implementing Frobenius norm: square, sum, square root
- Creating functions in APL with minimal code

#### 3. Tensor Operations
- Understanding tensors of different ranks
- Indexing into tensors: `m[2]` is the same as `m[2, :]`
- Using PyTorch operations instead of loops

#### 4. Broadcasting
- Key concept: operations between tensors of different shapes
- Simple case: scalar broadcast across a tensor
- More complex case: broadcasting vectors across matrices
- Rules for broadcasting:
  - Compare shapes from right to left
  - Dimensions are compatible if they're equal or if one is 1
  - Missing dimensions are treated as 1

#### 5. Advanced Broadcasting Techniques
- Using `unsqueeze` or `None` to insert unit dimensions: `c[None, :]` vs `c[:, None]`
- Creating outer products with broadcasting
- Using broadcasting for image normalization
- Applying broadcasting to matrix multiplication

### Final Optimization
- From 500ms initial implementation to ~0.1ms (5000x speed improvement)
- Fast enough to process the entire dataset instead of mini-batches
- 50,000 images processed in 656ms
