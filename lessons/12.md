# Lesson 12: Deep Learning Foundations to Stable Diffusion

## Introduction: CLIP Interrogator

- CLIP Interrogator is a Hugging Face Spaces Gradio app that generates text prompts for CLIP embeddings
- Common misconception: These text prompts are NOT the prompts that would generate the original image
- The app produces often humorous but not technically accurate descriptions
- The fundamental issue relates to inverse problems in deep learning

### Understanding the Inverse Problem

- CLIP image encoder works by converting images into embeddings (smaller representations)
- This process is not reversible (like a function that maps everything to zero)
- Converting an embedding back to the original image is impossible
- Diffusion models attempt to approximate solutions to this inverse problem
- Stable Diffusion uses text embeddings (not image embeddings)
- CLIP was designed to make text and image embeddings similar for matching content

## Matrix Multiplication Implementation and Optimization

### Broadcasting Approach

- Previously worked on matrix multiplication with broadcasting
- Reduced the operation to one Python for loop (much faster than nested loops)
- Achieved a ~5,000x speedup from original implementation

### Einstein Summation Notation

- `torch.einsum` - compact representation for products and sums
- Syntax example: `torch.einsum('ik,kj->ij', m1, m2)`
  - Letters represent dimensions (i = rows, k = columns for first matrix, etc.)
  - Repeated letters indicate multiplication along those axes
  - Arrow separates inputs from outputs
  - Letters omitted from output are summed over
- Extremely concise way to express matrix multiplication: `torch.einsum('ik,kj->ij', m1, m2)`

### PyTorch Built-in Operations

- `@` operator: Python's built-in matrix multiplication (e.g., `x_train @ weights`)
- `torch.matmul`: PyTorch's matrix multiplication function
- These built-ins perform similarly to the `einsum` implementation

### GPU Acceleration

- GPUs perform operations in parallel
- To utilize a GPU, code must be structured to allow parallelization
- Implemented a "kernel" function that calculates one element of the result matrix
- Used NUMBA's CUDA module to compile Python code to GPU code
- CUDA implementation steps:
  1. Create kernel function with `@cuda.jit` decorator
  2. Copy data to GPU with `cuda.to_device`
  3. Launch kernel with threads/blocks configuration
  4. Copy result back to CPU with `copy_to_host`
- Simpler PyTorch GPU method: use `.cuda()` to move tensors to GPU and `.cpu()` to bring back
- Overall speedup: ~5 million times faster than original Python implementation

## Mean Shift Clustering

### Clustering Overview

- Cluster analysis finds groups of similar items without predefined classes
- Best for data where columns are the same kind of thing and have similar scales
- Mean Shift is particularly useful because it doesn't require specifying number of clusters

### Synthetic Data Creation

- Created 6 clusters with 750 samples each
- Generated random centroids and data points around them using multivariate normal distribution

### Mean Shift Algorithm Explanation

1. Start with a data point
2. Calculate distance between that point and all other points
3. Apply a weighting function (Gaussian kernel) that gives higher weights to closer points
4. Calculate weighted average of all points (closer points have more influence)
5. Move the original point to this weighted average position
6. Repeat for all points and for multiple iterations
7. Points naturally cluster around their "centers of gravity"

### Gaussian Kernel

- Function that decreases as distance increases
- Formula: `exp(-d²/(2*bw²))` where `d` is distance and `bw` is bandwidth
- Bandwidth determines how quickly weights diminish with distance
- Rule of thumb: Choose bandwidth to cover about 1/3 of your data
- Alternative simpler weighting: Triangular weighting function

### Implementation Details

1. Calculate distances between points using broadcasting
2. Apply Gaussian kernel to distances to get weights
3. Calculate weighted average:
   - Multiply each data point by its weight
   - Sum the weighted points
   - Divide by sum of weights
4. Update point positions and repeat

### Optimizing Mean Shift

- Initial implementation: Loop through each point individually (slow)
- Optimized version:
  - Use batch processing to handle multiple points at once
  - Use broadcasting to calculate distances efficiently
  - Implement with `torch.einsum` or matrix multiplication
  - Move computation to GPU
- Performance improved from ~600ms to ~1ms with GPU + optimized code
- Larger batch sizes generally provide better performance

### Animation of Mean Shift Process

- Used `matplotlib.animation.FuncAnimation`
- Created a function that updates points and plots them
- Simple way to visualize algorithm convergence

## Introduction to Calculus

### Derivatives Conceptual Overview

- Used car travel example: position vs. time
- Derivative = rate of change (slope of function)
- Speed/velocity is the derivative of position with respect to time
- For continuous functions, calculate slope over smaller and smaller intervals

### Calculus of Infinitesimals

- Conceptualize derivative as change in function over very small change in input
- The ratio: (f(t₁+d) - f(t₁)) / d as d becomes very small
- This approach is mathematically valid (calculus of infinitesimals)
- Chain rule (upcoming lesson): dY/dX = dY/dU × dU/dX

### Important Points for Deep Learning

- Automatic differentiation in PyTorch does the derivative calculations
- No need to memorize specific derivative rules
- Chain rule is the most crucial concept for understanding backpropagation
